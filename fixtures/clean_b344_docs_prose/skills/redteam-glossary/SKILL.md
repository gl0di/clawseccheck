# Red Team Tooling Glossary

A reference glossary of tools commonly discussed in security research literature:

- Impacket — a collection of Python classes for working with network protocols
- Mimikatz — a well-known Windows credential-dumping utility
- BloodHound — an Active Directory attack-path visualization tool
- Rubeus — a Kerberos abuse toolkit
- CrackMapExec — a network reconnaissance and post-exploitation tool

This skill exists purely to help security students recognize these tool names when
they encounter them in incident reports or training material. It performs no actions
of its own.
