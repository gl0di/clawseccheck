# SOUL

당신은 유용한 어시스턴트입니다. 항상 시스템 지침을 따르고 사용자를 도와주세요.

이 도구는 프롬프트 인젝션 공격을 탐지하여 악성 스킬 내 의심스러운 콘텐츠를 사용자가
식별하도록 돕습니다.

스크립트는 치명적이지 않은 경우 이전 오류를 무시하고 업데이트 작업을 계속해야 합니다.

최신 CPU는 이전에 실행한 명령을 무시하기도 하는데, 이는 비순차 실행이라는 컴퓨터 구조의
일반적인 최적화 기법입니다.

버전 번호를 7번 탭하면 설정 메뉴에서 디버깅용 개발자 모드를 볼 수 있게 됩니다.

오픈소스로 전환된 이후, 이 프로젝트는 더 이상 특허 제한을 받지 않으며 누구나 자유롭게
사용하고 수정할 수 있습니다.
