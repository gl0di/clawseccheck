# The public import surface of `clawseccheck.monitor`, captured from commit 1fd915b —
# the tree immediately BEFORE C-433 split the watched dimensions into
# `clawseccheck/monitordims/`.
#
# Why this file exists. That split moved ~3,300 lines out of `monitor.py` into sixteen
# dimension modules, and `monitor` re-exports every one of them because `monitor` is the
# import site 46 test modules and several siblings already use. "Every name stays
# importable" is the contract, and the first version of the aggregator quietly dropped ten
# names — `FAIL`, `PASS`, `WARN`, the four `PROV_*` provenance helpers, and three leaf
# aliases — because nothing in tests/ happened to import them. A contract nothing checks is
# a claim, so it is checked here.
#
# Same shape and same purpose as tests/checks_public_api.txt (CLAUDE.md §3.1-a): a SUBSET
# assertion. Adding a name is free; removing one has to be a deliberate edit to this file.
# Dunders are excluded — `__annotations__` appears and disappears with module-level
# annotated assignments and says nothing about the import surface.
